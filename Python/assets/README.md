# Assets

This directory holds redrawn HD assets for the Second Reality recreation.

All graphics are recreated at 3840×2160 (4K) resolution. The original IFF ILBM
(.LBM) files in `original/` are not used — every visual element is either
redrawn here or generated procedurally in the shaders/parts code.

## Convention

- Backgrounds: `<partname>_bg.png`
- Logos/sprites: `<partname>_logo.png`
- Fonts: `font_<name>.png` (bitmap font atlas)

## Status

Assets are added per part as each section is implemented.
