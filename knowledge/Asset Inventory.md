## Packed/Processed Data Files

These are intermediate or runtime formats:

| Extension | Description |
|---|---|
| `.UH` | Uncompressed Horizontal (scanline) data |
| `.U` | Uncompressed picture data |
| `.UP` | Packed (compressed) picture data |
| `.IN0` / `.IN1` | Packed/intermediate data (numbered variants) |
| `.BBM` | DeluxePaint BrushBitMap (brush/sprite file) |
| `.OBK` | Object binary (linked object data) |
| `.OBJ` | Assembled binary object (binary data linked into EXE) |
| `.DSK` | Floppy disk image |
